# 划词去向（L3 实现说明）

> 状态：现行。R57 引入、R78 补「自建 UI 点击不重采选区」。

## 实现

- `extension/common.js` 的 `__magicLensSelectionAction(text)` 是唯一去向判定：
  单个英文单词返回 `translate`，其他非空文本返回 `ai`，空文本返回 `none`。
- `__magicLensSelectionWord(text)` 统一取选区开头的英文词形（含直/弯撇号），
  「生词/认识/详解」与 iframe 路径共用，避免判定与取词口径漂移。
- `extension/content.js` 在 `openBubble()` 中消费该判定：
  - `translate` 且 `autoTranslate` 开启时，保持原有自动翻译；
  - `ai` 时不发翻译请求，突出「AI」主按钮，隐藏不能用于普通文本的「详/认识/生词」；
  - 「译」仍保留为手动操作，用户可显式翻译短语、句子或中文。
- **自建 UI 点击不重采选区（R78）**：`mouseup` 若落在任意 `#magiclens-*` host 内
  （气泡/伴读抽屉/悬浮球/段落 chip/朗读工具），直接忽略、不排 60ms 后的
  `processSelection`。否则点击气泡按钮会因选区仍在而重开气泡，把 `current`、`seq`
  与「翻译中…」文案一起重置，在途回包按判代规则丢弃——真机表现就是「点『译』没反应」。
- `extension/chat.js` 的 `open(text)` 把选区原文直接写入伴读输入框，不添加引用符号，
  并把光标放到末尾；不自动发送。
- `scripts/check-selection-ai.js` 加载真实 `common.js`，锁住单词/短语/中文/数字/
  标点/空文本的判定矩阵。

## 边界

- 单词口径与划词朗读一致：首尾必须是 ASCII 字母，词内可含直撇号、弯撇号或连字符。
- 只要包含中文就归入 AI，即使选区里同时有英文单词。
- `MAX_LEN=2000` 是翻译接口上限，自动与手动「译」都检查；AI 选区复制阶段不按
  该上限拦截，发送时沿用 `chat.js` 既有的 4000 字上限。
- 旧翻译请求返回时若当前选区已更换或气泡已关闭，响应作废，不得覆盖新的 AI 提示。
- 点击气泡内按钮（✕/认识/生词/详解/🔊/AI/译）不改变当前选区与气泡状态机；只有页面
  正文里的新划选才会触发重采。
- 悬浮生词与点高亮词本身就是单个英文单词，仍走即时翻译；iframe 选区与顶层选区
  共用 `openBubble()`，去向一致。
