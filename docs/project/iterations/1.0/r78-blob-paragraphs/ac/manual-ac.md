# R78 手工 AC · 正文块兼容 + 气泡「译」

> 版本：0.8.39-202611271639 测试版。加载 `magiclens/extension/` 后刷新目标页。

1. 打开 Google 账号社区帖子（正文在 `<html-blob>` 里、页面无 `<p>`），选中一段英文，
   气泡出现「已选中，点「AI」…或点「译」手动翻译」，**停留 1 秒以上**再点「译」。
   期望：气泡出现「翻译中…」并在完成后显示译文（不再回到原提示）。
2. 同一页，鼠标移到正文段落上按 `Alt+P`。期望：该段下方出现译文块，底部 chip 显示
   「段落翻译 · 已译 1 段」；再按一次撤销，译文块消失。
3. 同一页，鼠标移到正文段落末行。期望：行尾出现 ▶ 与 译 两个小圆钮（只此两个）。
   点「译」→ 该段译文出现、按钮进入已译态；再点 → 撤销且不再发请求。
4. 点气泡里的 ✕ / 认识 / 生词 / AI / 🔊 后，气泡状态不得被“重开”回初始提示；
   点「译」期间按钮/文案保持（无闪烁复位）。
5. 普通 `<p>` 文章页（如 Anthropic 文章）回归：划词气泡、`Alt+P`、段末 ▶/译、
   整页 `Alt+A` 与朗读 `Alt+S` 行为与 v0.8.38 一致。
6. `html-blob` 内含标准 `<p>` 的页面（构造或真实站点）：整页翻译只翻内层段落，
   不得同一段出现两条译文（外层 blob 被跳过）。
