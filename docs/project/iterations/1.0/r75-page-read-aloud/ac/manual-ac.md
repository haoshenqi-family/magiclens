# R75 手工验收清单

> 状态：待真机验收（2026-11-27）。加载 `extension/` 后按序执行。

1. 英文长文页（Anthropic / Wikipedia）鼠标移到正文段落 → 最后一行末尾出现小圆 ▶。
2. 点击后默认 AI 音读该段，图标变 ■；再点 ■ 停止；段末位置与 magicbook 阅读器一致（不压正文）。
3. 控制条进度正确；暂停/继续、下一段、停止均生效。
4. 语速 1.0/0.75/0.5 循环且不变调；刷新后档位保持。
5. `Alt+S` 从当前视口起整页连播并自动滚屏；再按停止。
6. 右键「MagicLens 朗读本段」与「朗读全文 / 停止」均可用。
7. 选中段落内一句话右键「朗读本段」→ 读整段。
8. 未登录/积分不足 → 控制条上方显示可行动文案，不静默。
9. 同一段停止后重播 → Network 无新 `/tts/speak` 请求。
10. magicbook 阅读器页无双朗读 UI；禁用域名页零 UI。
