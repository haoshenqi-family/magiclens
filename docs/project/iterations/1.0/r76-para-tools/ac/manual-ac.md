# R76 手工验收清单（段末工具：▶ / 译）

> 状态：待真机验收（2026-11-27）。加载 `extension/` 后按序执行。

1. 英文长文（Anthropic / Wikipedia）鼠标移到正文段落 → 最后一行行尾出现两个小圆：`▶` `译`。
2. 短标题（如文章 H1，<40 字符）→ 只有 `▶`，不出现点了报错的 `译`。
3. 点 `译` → 只翻当前这一段（Network 里 `translate-batch` 的 `paragraphs` 长度为 1），
   译文块出现在该段下方，`译` 变淡。
4. 再点 `译` → 译文块收起，零新请求；再点一次复活，仍零新请求（页内缓存）。
5. `Alt+P` 与段末 `译` 操作同一段互为同步（一边译了，另一边按钮为已译态）。
6. 点 `▶` 朗读该段，播放中变 `■`，再点停止；与 `译` 互不干扰（可同时存在）。
7. 段末按钮组贴最后一行行尾、滚动时跟随段落，不遮挡正文；窗口缩窄/满行时落到行下右对齐。
8. `译` 请求期间显示 `⟳`，失败时出可见文案，不静默。
9. 网域禁用名单站点 / 主开关关闭 → 零段末 UI。
10. magicbook 阅读器页不出现第二套段末工具（iframe 不装配 + 域让位）。
