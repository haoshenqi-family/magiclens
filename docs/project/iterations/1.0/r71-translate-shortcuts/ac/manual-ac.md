## 快捷键触发（默认键位）

- [ ] AC1 英文页按 `Alt+A` → 整页翻译开启（左下 chip「段落翻译 · 已译 N 段」、译文块渐现），再按 `Alt+A` → 关闭、译文块与 chip 全部移除——与悬浮球「🌐 整页翻译」/popup 按钮同语义。
- [ ] AC2 鼠标悬停某正文段落（不开启整页模式）按 `Alt+P` → 仅该段出现译文块 + chip 进度；再按 `Alt+P` → 仅撤销该段译文。
- [ ] AC3 同一段按 `Alt+P` →`Alt+P`→`Alt+P`：第三次零网络请求（页内缓存复活，DevTools Network 佐证）。
- [ ] AC4 先 `Alt+P` 单段后 `Alt+A` 整页：批量请求只含其余段落（首段走缓存），总渲染不缺段、不重复计费。
- [ ] AC5 macOS 上 Option 组合生效（`e.code` 匹配，死键字符 å/π 不影响）。
