# R72 AC 手工清单（chrome://extensions 重载实测）

## 双击 Alt / ⌥ 整页别名

- [ ] AC1 500ms 内连按两次 Alt → 整页翻译开（同 Alt+A）；再连按两次 → 关。
- [ ] AC2 Mac 上连按两次 ⌥Option → 同样切换整页翻译。
- [ ] AC3 单按一次 Alt（不成双）零反应，浏览器/网页自身行为不受干扰。
- [ ] AC4 `Alt` → `A`（即 Alt+A 组合）后紧跟单次 Alt：不误判为双击（其他键断连击）。
- [ ] AC5 两次 Alt 间隔 >0.5s：不触发（窗口外）。
- [ ] AC6 编辑框聚焦时双击 Alt 不触发；域名禁用站双击 Alt 零反应。

## Shift 悬停单段

- [ ] AC7 鼠标悬停英文正文段落按一次 Shift → 该段出现译文（同 Alt+P）；再按 Shift → 撤销该段。
- [ ] AC8 悬停在页边空白/图片上按 Shift → 提示「未找到可翻译段落」。
- [ ] AC9 Shift+Tab / Shift+方向键 / 编辑框内 Shift+字母：不触发翻译。
- [ ] AC10 悬停单段后 Shift+点击扩展选区（选区扩展）：不产生重复译文块。

## Mac 与录制器

- [ ] AC11 Mac 上 `⌥A` / `⌥P` 即 Alt+A / Alt+P（设置页显示 `Alt+A` 字样即可用）。
- [ ] AC12 录制框里只按单个修饰键（Alt/Ctrl/⌘/Shift）：继续等待不录出怪串，按真组合键才落值。
- [ ] AC13 设置页「快捷键」节文案包含双击 Alt 与 Shift 悬停两个固定别名说明及 Mac ⌥ 提示。
